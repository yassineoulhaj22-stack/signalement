# Signalement (بلّغ) – Android

HTML/CSS/JS + Capacitor + Leaflet (cartes OpenStreetMap, internet requis pour les tuiles).
1. Envoyez TOUS les fichiers de ce ZIP dans un dépôt GitHub (dossiers `www`, `resources`, `.github` inclus).
2. Actions > Build APK > Run workflow, puis téléchargez l'artefact `signalement-apk`.
Code: `www/app.js`, `www/style.css`. Images: `www/img/`.
